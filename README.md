# 🏝️ ㄅㄆㄇ 快樂冒險島 (Bopomofo Adventure Island)

> 專為台灣小一新生量身打造的生動國語注音符號互動學習系統！🇹🇼✨  
> 涵蓋台灣教育部小學一年級前十週注音符號教學範圍，結合遊戲化闖關、四聲滑動調值、神奇拼音火車與標準米字格描紅練習。

---

## 🌟 核心教學與闖關特色

本系統依據台灣教育部國語注音符號教學指引（聽、說、讀、寫、拼音、聲調）設計，打造「RPG 勇者闖關地圖」結合六大生動互動專區：

### 0. 🗺️ 勇者闖關大冒險（10 大主題關卡＋守關魔王對戰）
* **循序漸進 10 大島嶼關卡**：對齊小一前十週注音進度（微風森林 `ㄅㄆㄇㄈ` ➔ 陽光草原 `ㄉㄊㄋㄌ` ➔ 恐龍山谷 `ㄍㄎㄏ/ㄐㄑㄒ` ➔ 翹舌神殿 `ㄓㄔㄕㄖ vs ㄗㄘㄙ` ➔ 精靈湖畔 `ㄧㄨㄩ/單韻母` ➔ 彩虹吊橋 `複韻母/鼻韻母` ➔ 雲霄飛車 `四聲調值` ➔ 魔法火車站 `兩拼合音` ➔ 水晶城堡 `結合韻三拼` ➔ 魔王寶藏島 `黃金巨龍終極試煉`）。
* **星光魔法對戰與 HP 血條**：每關皆有專屬守關精靈（小狐狸、暴龍阿卡、神殿小青龍、黃金注音巨龍等），答對題目即可發射星光閃電扣減魔王 HP！
* **三星評價與勇者升等系統**：支援愛心生命值（❤️❤️❤️）、連擊 Combo、老師語音提示與三星通關紀錄，並提供老師/家長專用的「🔓 自由選關模式」。

### 1. 🌈 37注音探險圖鑑
* **完整符號庫**：涵蓋 21 聲母、3 介音、13 韻母以及 22 個常見結合韻（ㄧ、ㄨ、ㄩ 系列）。
* **萌系生活聯想詞**：如 ㄅ斑馬 🦓、ㄆ蘋果 🍎、ㄇ貓咪 🐱、ㄈ飛機 ✈️、ㄉ大象 🐘 等生活好朋友。
* **小一必背記憶口訣**：如「ㄅ像收音機，天線豎起來 ㄅㄅㄅ」、「ㄆ像小水盆，潑水嘩啦啦 ㄆㄆㄆ」。
* **筆順拆解引導**：提供每一符號之總筆劃數與筆劃順序走向提示。

### 2. 🚂 神奇拼音小火車
* **自由兩拼與三拼合音**：挑選「聲母車廂 ＋ 介音車廂 ＋ 韻母車廂 ＋ 聲調旗幟」。
* **循序漸進拼讀教學**：點擊開動火車，先唸分音（例如「ㄕ～、ㄨ～、ㄤ～」），再唸合音（「拼成 雙！是一雙鞋子的雙喔！」）。
* **隨機抽題換字**：內建 400+ 組教育部常用國字字詞庫，可一鍵隨機挑戰生活常見詞彙。

### 3. 🎢 四聲溜滑梯
* **圖像化五度標調法**：將小一生最容易混淆的四聲調值（一聲高平 55、二聲中升 35、三聲降升 214、四聲全降 51、輕聲短輕）具象化為動態滑梯與過山車！
* **音高滑動音（Pitch Sweep）**：以純合成音頻即時滑動音高，加深對高低升降的音感直覺。
* **經典口訣朗讀**：一聲平平的一條線、二聲往上爬山坡、三聲轉個彎、四聲溜滑梯往下衝、輕聲輕輕點！

### 4. 🎮 趣味小遊樂園（三合一闖關遊戲）
1. **🎈 聽音戳氣球**：聽標準國語發音，在浮動的彩色氣球中選出正確符號，戳破伴隨啵啵聲與星光獎勵！
2. **🃏 注音配對連連看**：翻牌記憶遊戲，將注音符號與對應插圖成功配對。
3. **🎯 聲調小偵探**：聆聽生活詞彙，辨識文字屬於第幾聲，培養精準聽音辨調能力。

### 5. ✍️ 筆順小畫家
* **國小標準米字格**：提供標準虛線十字米字格背景與注音底字浮水印。
* **五彩粉蠟筆與橡皮擦**：支援滑鼠與觸控筆/手指平滑描摹。
* **集星好棒印章**：描寫完成後點擊「寫好了領星星」，在米字格上蓋上金色「⭐ 好棒」印章！

### 6. 🏆 榮譽星光榜
* **激勵機制**：答對題目、完成拼音或認真練寫即可累積金星星。
* **解鎖成就勳章**：如「注音探險家」、「聲母神射手」、「拼音小達人」、「聲調特技王」、「筆順小神筆」，激發孩子源源不絕的學習動機。

## 💻 快速開始 (Quick Start)

本專案為純前端單頁應用程式（HTML5 + Vanilla CSS + JavaScript），無須任何複雜建置步驟：

1. **直接開啟**：
   雙擊 `index.html` 即可在任一現代瀏覽器（Chrome, Edge, Safari, Firefox）中直接暢玩。

2. **本地啟動**：
   ```bash
   # Python 3
   python -m http.server 8080
   ```
   瀏覽器開啟 `http://localhost:8080` 即可體驗！
